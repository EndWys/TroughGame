# Subtask Architecture Artifacts

Create `FEAT-XX.md` for each approved local architecture. Record its path/status
in the matching `subtasks` entry in `state.yaml`.
Include approved scope/outcome, change inventory, contracts, execution chain,
Unity integration, applicable lifecycle map, design choices, validation, and approval
reference. The format owner is [subtask architecture](../../../../.agents/skills/unity-feature-development/references/subtask-architecture.md).
