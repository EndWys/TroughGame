# Notion Project Documentation Standard

## Canonical Source

Use the live [TroughGame documentation standard](https://app.notion.com/p/3f7ad1247d5881409ce4f30510f6a1b0).
Read it via Notion MCP inside the permitted requirements/finalization worker call.
It governs Notion content language, structure and presentation; do not maintain a
competing local copy or install another documentation workflow.
`docs/notion/project.json` retains the verified page ID and other static mappings.

## Scope

The standard is presentation guidance, not authorization to publish progress or
run additional operations. The [two invocation points](feature-integration.md)
remain authoritative even if a remote page recommends ongoing progress reporting.
Local agent instructions remain English. Preserve historical requirements and
distinguish owner acceptance from actual game/network test execution.
